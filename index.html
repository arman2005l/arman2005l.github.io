زیرساخت فروش خودکار کانفیگ VPNAutomated VPN Configuration Sales Infrastructure

سیستم خودمیزبان فروش کانفیگ VPN که از ابتدا روی سرورهای شخصی لینوکس طراحی و پیاده‌سازی شده است. Xray-core و sing-box از طریق gRPC مستقیم مدیریت می‌شوند؛ سرویس شامل ربات تلگرام با aiogram، دیتابیس، سرویس اشتراک و Nginx reverse proxy با SSL خودکار است. وبهوک پرداخت رمزارزی با HMAC اعتبارسنجی می‌شود و از طریق شبکه‌ی داخلی ایزوله‌ی Docker با API داخلی ربات ارتباط دارد. تطبیق خودکار پرداخت ریالی با پیامک بانکی در حال توسعه است.A self-hosted VPN configuration sales system designed and implemented on personal Linux servers. Xray-core and sing-box are managed over direct gRPC. The services include an aiogram Telegram bot, database, subscription service, and Nginx reverse proxy with automatic SSL. Crypto payments use an HMAC-verified webhook that communicates with the bot’s internal API over an isolated Docker network. Automated IRR payment matching using bank SMS is in development.

OpenGate VPN · Sales InfrastructureOpenGate VPN · زیرساخت فروش

A self-hosted service built with Xray-core and sing-box for VLESS+Reality, Hysteria2, and TUIC. Docker Compose runs the aiogram sales bot, subscription service, and supporting services; the bot manages proxy users through direct gRPC. Nginx provides reverse proxy and automatic SSL. Crypto payment uses an HMAC-verified webhook over an isolated internal Docker network. Automated IRR payment matching from bank SMS is in development.سرویسی خودمیزبان بر پایه‌ی Xray-core و sing-box برای VLESS+Reality، Hysteria2 و TUIC. ربات فروش aiogram، سرویس اشتراک و سرویس‌های پشتیبان با Docker Compose اجرا می‌شوند و ربات از طریق gRPC مستقیم کاربران هسته‌ی پروکسی را مدیریت می‌کند. Nginx reverse proxy و SSL خودکار را فراهم می‌کند. پرداخت رمزارزی با وبهوک HMAC-verified روی شبکه‌ی داخلی ایزوله‌ی Docker انجام می‌شود. تطبیق خودکار پرداخت ریالی با پیامک بانکی در حال توسعه است.
